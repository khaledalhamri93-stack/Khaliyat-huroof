# خلية حروف

لعبة «خلية حروف» الإلكترونية لأسبوع اللغة العربية «أسبوع الضاد» — مدرسة سافرة الابتدائية الإعدادية للبنين.

- فريقان بأسماء يختارونها (الأخضر يصل بين اليمين واليسار، والبرتقالي بين الأعلى والأسفل).
- إعدادات: وقت السؤال، نقاط كل إجابة، مستوى الأسئلة (الأول–الثالث الابتدائي / الرابع الابتدائي–الثالث الإعدادي)، من يبدأ، ترتيب الحروف، الصوت.
- تُفتح من ملف `index.html` مباشرة، أو عبر GitHub Pages.
